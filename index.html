Clash of Arms

Combat Comparator · One Round

Load a unit from the Grimoire (or fill in the fields by hand) to get its defensive profile plus one row per weapon it carries. Untick a weapon's box to leave it out of this particular clash without losing its stats — handy for comparing loadouts, like a champion's alternate weapon or a monster's secondary attack, one at a time. Set a row's "Models" to how many models actually swing it (leave blank to mean all models in the unit). Values change between editions and points updates, so double check against the live warscroll. Attacks and Damage accept dice notation like D6, 2D6 or D3+1. This runs a single combat round in each direction and ignores spillover, abilities, and command points — a rough guide, not a rules engine.

Import units & faction rules from JSON files

Point this at the files in your converter's output/ folder — select as many as you like at once (desktop: ctrl/cmd-click or shift-click in the file dialog to multi-select several factions in one go). Each entry can have a weapons array — [{"name":"...","models":"","attacks":"1","hit":"4","wound":"4","rend":"0","damage":"1"}] — for units with more than one weapon profile. Old-style flat fields (attacks, hit, wound, rend, damage) still import fine and are treated as a single weapon. .rules.json files (faction rules with battle formations, artefacts, heroic traits and boons) are detected automatically and power the Army Rules panel in the Order of Battle tab. Entries matching an existing name + faction are updated in place, so it's safe to re-import after a battletome update.
