Import units from JSON files

Point this at the files in your converter's output/ folder — select as many as you like at once (desktop: ctrl/cmd-click or shift-click in the file dialog to multi-select several factions in one go). Each file should hold an array of entries with fields like name, faction, points, models, wounds, save, attacks, hit, wound, rend, damage, abilities. Entries matching an existing name + faction are updated in place, so it's safe to re-import after a battletome update.
